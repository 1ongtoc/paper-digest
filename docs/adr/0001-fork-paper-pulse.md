# Fork Paper Pulse as the implementation base

The project will derive from Jamie-Cui/paper-pulse and reuse its working IACR/arXiv fetching, filtering, summarization pipeline, deduplication, and digest generation where they fit. Because the upstream project is GPL-3.0, this derivative will preserve attribution and remain GPL-3.0; unrelated upstream features may be removed instead of reimplemented.
